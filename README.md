# 智宿 · 学生宿舍生活服务平台

面向在校学生的宿舍生活服务平台，将宿舍信息、在线报修、调宿申请、卫生记录、水电查询和通知公告集中到统一入口。项目同时保留隐藏的管理辅助端。

## 技术栈

- Vue 3 + TypeScript + Vite
- Vue Router + Pinia
- Element Plus
- Express 5 REST API
- JSON 文件持久化（便于零配置演示）
- 响应式后台布局

## 本地运行

```bash
npm install
npm run dev
```

## 学生端功能

- 学号登录、登录状态持久化与路由守卫
- 响应式顶部导航与移动端抽屉菜单
- 学生首页、宿舍信息、舍友和宿管联系方式
- 在线提交报修与处理进度时间线
- 调宿申请、重复申请校验和办理流程
- 卫生评分、分项成绩和历史检查记录
- 水电用量、待缴账单和历史账单
- 通知分类、搜索与已读状态
- 个人资料和账号安全入口
- 学生晚归登记、重复登记校验与历史记录
- 真实账号校验、Bearer Token 鉴权与统一接口异常处理
- 报修、调宿、通知等服务端业务校验和数据持久化

宿管端通过 `/admin` 访问，提供工作台、楼栋、房间、学生、报修与晚归管理。晚归记录支持联系学生和确认返回，学生与宿管接口采用角色权限隔离。
